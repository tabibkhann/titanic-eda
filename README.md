# Titanic Exploratory Data Analysis (EDA)

## Project Overview

This project explores the Titanic passenger dataset to understand passenger characteristics, data quality, and factors associated with survival.

## Objectives

- Inspect and summarize the dataset.
- Identify missing values and explore data distributions.
- Analyze survival rates across passenger classes and sex.
- Explore passenger titles extracted from names.
- Investigate family relationships and age patterns.

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Analysis

The notebook includes data inspection, missing-value analysis, descriptive statistics, visualizations, survival-rate comparisons, passenger-title analysis, and family-related feature exploration.

## Dataset

The analysis uses the Titanic training dataset, commonly available through the Kaggle Titanic competition.

Download the dataset from the [Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic/data). Place `train.csv` in the notebook's working directory before running the notebook.

## How to Run

1. Download or clone this repository.
2. Obtain the dataset described above.
3. Open `titanic_eda.ipynb` in Google Colab or Jupyter Notebook.
4. Ensure `train.csv` is accessible at the path expected by the notebook.
5. Run the notebook cells in order.
